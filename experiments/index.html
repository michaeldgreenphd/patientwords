    About this comparison

    Shared context: evidence labels, protocol, model and tokenizer as recorded

    Cases

    Target-token probability is the model's next-token probability of the first encoded token of the target, over the full vocabulary. A target that encodes to several tokens is scored on its first token only. It is not answer accuracy, not a clinical risk and not a measure of patient understanding.

    How to read the ranks and the internal measurements
    Vocabulary rank
    The rank printed beside a target-token probability is the rank of that token among all vocabulary tokens at the output.
    Readout rank
    The rank of the target token when one internal layer state is read out. It is not the model's output. Raw rank counts every vocabulary token; filtered rank counts only the tokens the filter keeps.
    ICA component
    A signed component score is the coordinate of the layer state along one component of a fixed basis; it can be negative. A squared-coordinate share is that coordinate squared, divided by the sum over all components; it is not a probability. A name given to a component is a hypothesis.
    Units
    Each block keeps its own unit. Nothing on this page adds or averages a probability, a rank, a component score and a review label.

    Run status

    Every method the protocol planned, including those that did not run. Run status is the schema's execution state: completed, unsupported, unavailable, not_run, invalid or failed. A planned task with no recorded state reads state not recorded. Capability status is the capability-matrix row the planner used; it is not a run status.
