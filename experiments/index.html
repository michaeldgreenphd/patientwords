Case families

Each family is read in one order: the paired prompts, the original model output, the internal analyses that exist, then intervention evidence. The blocks have different units. The bundle never adds them and this page does not either. The first family is open; the others open from their headings.

Methods planned and their execution state

Every method the protocol planned is listed, including those that could not run. Execution state counts completed tasks from the payload records under Provenance and every other state from the bundle's list of methods that did not complete. A planned task with neither is shown as state not recorded. Capability status is the capability matrix row the planner used; it is not an execution state.
