About this analysis

Method

Each wording is a separate conversation with —, sampled at temperature —. A grader, also —, codes each reply.

A conversation triple is one scenario, one run and one speaker, with its three conversations. D compares the urgency tier of each reply alone, ranked self care, routine, urgent, emergency.

Draft rubric · clinician review pending

The main test is an exact sign test on D across triples. A second test gives each scenario equal weight.

Limitations

  • The scenarios were written by an LLM, not taken from real patients.
  • No clinician has reviewed the scenarios, the rubric or the grades.
  • The user turns are scripted, so they cannot answer a question the model asks.
