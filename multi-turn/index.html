Method

Each scenario is a fixed script of user turns, written once and sent in three wordings: colloquial, careful lay and clinical.

Each wording is a separate conversation with —, sampled at temperature —. A grader, also —, codes each reply.

A conversation triple is one scenario, one epoch and one speaker, with its three conversations. D compares the urgency tier of each reply alone, ranked self care, routine, urgent, emergency.

The primary test is an exact two-sided sign test on the sign of D across triples. A second test treats each scenario as one unit, so a claim beyond these scenarios does not rest on one of them.

The analysis plan was fixed before the prospective triples were generated. It is section 10 of the engine’s wave-2 design note.

Limitations

  • The scenarios were written by an LLM, not taken from real patients.
  • No clinician has reviewed the scenarios, the rubric or the grades.
  • The user turns are scripted, so they cannot answer a question the model asks.
  • One model was tested: Claude Haiku 4.5.
  • The grader is the same model as the one being tested.
  • The test has little power at this size. A result that is not significant is inconclusive, not evidence that wording makes no difference.
